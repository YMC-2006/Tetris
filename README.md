# Tetris

Proyecto I de **EIF207 — Estructuras de Datos** de la Universidad Nacional de Costa Rica.

## Descripción

Implementación de una versión simplificada de **Tetris** en C++, aplicando estructuras de datos lineales y algoritmos de ordenamiento estudiados en el curso.

## Tecnologías

* C++
* ZinjaI
* raylib 4.0
* Git

## Estructuras utilizadas

* Cola de piezas
* Pila para Hold
* Lista doblemente enlazada para Replay
* Cola de eventos
* Lista enlazada para el tablero
* Algoritmos de ordenamiento para la tabla de puntajes

## Ejecución

El proyecto se ejecuta utilizando **ZinjaI** con la configuración de **raylib 4.0** establecida para el proyecto.
